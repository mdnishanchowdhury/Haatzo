Haatzo - Modern Grocery E-Commerce Platform
Haatzo is a full-featured, responsive e-commerce web application designed for a seamless grocery shopping experience. It features a clean UI, dynamic product filtering, and a robust category-based navigation system.

🚀 Features
Dynamic Homepage: Features high-impact hero sliders, weekly offer banners, and "Best Sellers" sections with countdown timers.

Advanced Filtering: A dedicated shop sidebar allowing users to filter by:

Price Range: Interactive slider and manual input.

Categories: Multi-level navigation (Fruits, Meats, Dairy, etc.).

Product Attributes: Filter by Color, Brand, and Stock Status.

User Interface: * Responsive design for desktop and mobile.

Wishlist and Cart management indicators.

Clean product cards with "Add to Cart" and "Quick View" capabilities.

Footer & Newsletter: Integrated subscription form and comprehensive site mapping.

🛠️ Tech Stack
Frontend: React.js / Next.js (indicated by .vercel.app domain)

Styling: Tailwind CSS / Styled Components

Deployment: Vercel

🏁 Getting Started
Prerequisites
Node.js (v18 or higher)

npm or yarn

Installation
Clone the repository:

Bash

git clone https://github.com/your-username/haatzo.git
cd haatzo
Install dependencies:

Bash

npm install
Run the development server:

Bash

npm run dev
Open http://localhost:3000 to view the result.

📂 Project Structure
/components - Reusable UI elements (Product cards, Filters, Nav)

/pages - Main application routes (Home, Shop, Categories)

/public - Static assets and images

/styles - Global CSS and theme configurations
