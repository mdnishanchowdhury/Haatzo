# Haatzo - Modern Grocery E-Commerce Platform

Haatzo is a full-featured, responsive e-commerce web application designed for a seamless grocery shopping experience. It features a clean UI, dynamic product filtering, and a robust category-based navigation system.

---

## 🚀 Features

### Dynamic Homepage
- High-impact hero sliders
- Weekly offer banners
- "Best Sellers" sections with countdown timers

### Advanced Filtering
- **Price Range**: Interactive slider and manual input
- **Categories**: Multi-level navigation (Fruits, Meats, Dairy, etc.)
- **Product Attributes**: Filter by Color, Brand, and Stock Status

### User Interface
- Responsive design for desktop and mobile
- Wishlist and Cart management indicators
- Clean product cards with "Add to Cart" and "Quick View" capabilities

### Footer & Newsletter
- Integrated subscription form
- Comprehensive site mapping

---

## 🛠️ Tech Stack

- **Frontend:** React.js / Next.js (Vercel deployment)
- **Styling:** Tailwind CSS / Styled Components
- **Deployment:** Vercel

### Installation Steps for Haatzo Project

### Step 1: Clone the Repository
Copy the repository to your local machine:
```bash
git clone https://github.com/mdnishanchowdhury/Haatzo.git
```
This will create a folder named Haatzo in your current directory containing the project files.

### Step 2: Navigate to the Project Folder
```bash
cd Haatzo
```
Now you are inside the project folder where the package.json file is located.

### Step 3: Install Dependencies
```bash
npm install
```
This will install all required packages including React, Tailwind CSS, Styled Components, Recharts, and more.
### Step 4: Run the Development Server
```bash
npm run dev
```
This will start the project locally. By default, it runs on http://localhost:5173.

### Step 5: Open in Browser
Open your browser and visit:
http://localhost:5173
You should now see the Haatzo website running on your local machine.
